# PROYECTO: OMNILEADS AI

Quiero crear un nuevo módulo dentro de OmniTech Core llamado "OmniLeads AI".

OBJETIVO

Crear un sistema de prospección inteligente que permita encontrar empresas reales, analizarlas automáticamente con IA y convertirlas en oportunidades de venta dentro del CRM de OmniTech.

IMPORTANTE

Este módulo NO debe ser una aplicación independiente.

Debe integrarse completamente dentro de OmniTech Core, utilizando el mismo sistema de autenticación, permisos, base de datos, workspaces, diseño, componentes y arquitectura existentes.

--------------------------------------------------

- Sector
- Ciudad

- Radio en kilómetros
- Número máximo de resultados

--------------------------------------------------

Quiero que OmniLeads AI sea el mejor módulo de prospección comercial dentro de OmniTech Core.

La implementación debe ser limpia, profesional, escalable y lista para seguir creciendo en futuras versiones.
