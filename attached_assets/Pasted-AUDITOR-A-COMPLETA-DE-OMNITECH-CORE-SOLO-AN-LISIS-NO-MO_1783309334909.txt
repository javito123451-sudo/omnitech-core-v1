AUDITORÍA COMPLETA DE OMNITECH CORE (SOLO ANÁLISIS - NO MODIFICAR CÓDIGO)

Quiero realizar una auditoría técnica completa de OmniTech Core antes de hacer cualquier cambio importante.

NO debes modificar archivos, eliminar código, refactorizar ni corregir errores. Tu única misión es inspeccionar el proyecto y generar un informe detallado.

⸻

1. ARQUITECTURA GENERAL

Analiza:

* Estructura completa del proyecto.
* Frameworks y librerías utilizadas.
* Dependencias instaladas.
* Variables de entorno requeridas.
* Flujo de autenticación.
* Flujo de autorización.
* Organización de carpetas.
* Calidad de la arquitectura.

Indica puntos fuertes y puntos débiles.

2. BASE DE DATOS

Realiza un inventario completo.

Para cada tabla indica:

* Nombre.
* Finalidad.
* Relaciones.
* Claves.
* Índices.
* Si está siendo utilizada.
* Si contiene datos de prueba.
* Si parece obsoleta.
* Si puede eliminarse.
* Si necesita cambios.

Detecta:

* Tablas duplicadas.
* Campos duplicados.
* Relaciones incorrectas.
* Datos huérfanos.
* Problemas de integridad.
