IMPLEMENTAR “OMNI DIAGNOSTICS”

OBJETIVO

Crear un módulo nativo de OmniTech capaz de realizar un diagnóstico completo del sistema, detectar errores automáticamente y proponer acciones correctivas.

Debe funcionar para cualquier Workspace.

⸻

UBICACIÓN

Nuevo módulo:

Platform
└── Diagnostics

Acceso:

Super Admin

Administradores de Workspace (solo su Workspace)

Mostrar:

🟢 Sistema operativo

🟡 Advertencias

🔴 Errores críticos

Puntuación de salud del Workspace (0-100).

ARQUITECTURA

El módulo debe ser completamente independiente.

Todo nuevo módulo deberá registrar automáticamente su propio Diagnostic Adapter para que Omni Diagnostics pueda comprobar su estado sin modificar el Core.

No crear lógica específica para WhatsApp ni para ningún módulo concreto.

Diseñar una arquitectura extensible basada en adaptadores.
