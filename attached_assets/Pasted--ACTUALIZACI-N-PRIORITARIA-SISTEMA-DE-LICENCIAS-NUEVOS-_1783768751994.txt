=========================================================
🔴 BUG CRÍTICO - EL SISTEMA DE LICENCIAS NO SE RESPETA
=========================================================

## Problema detectado

En el Control Center tengo desactivados varios módulos para un Workspace.

Sin embargo, cuando inicio sesión con un usuario perteneciente a ese Workspace y entro en la aplicación (por ejemplo al crear un cliente nuevo), aparecen TODOS los módulos como si estuvieran contratados.

Esto rompe completamente el sistema de licencias.

Actualmente un cliente puede visualizar módulos que NO ha contratado.

Eso no puede ocurrir.

---------------------------------------------------------

## Comportamiento esperado

Cada Workspace únicamente podrá:

✔ Ver los módulos contratados.

✔ Acceder únicamente a los módulos contratados.

✔ Utilizar únicamente los módulos contratados.

Los módulos NO contratados deben quedar completamente ocultos.

No deben aparecer:

- Dashboard
- Menú lateral
- Formularios
- Crear Cliente
- Marketing
- Automatizaciones
- IA
- Facturación
- Configuración
- Ningún selector
- Ningún acceso rápido

Tampoco deberán poder abrirse:

- Mediante URL directa
- Mediante llamadas a la API
- Mediante enlaces internos
